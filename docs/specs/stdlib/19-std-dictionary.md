# Standard library spec 19: std.Dictionary

## Scope

This specification rules the mutable hash keyed table of the subset,
`std.Dictionary<K, V>`, the structure spec 07 (`stdlib/07`)
reserved for a mutable long-lived keyed cache. Where
`std.SortedMap` is the immutable, ordered, comparison-based table,
`std.Dictionary` is the mutable, unordered, hash-based table. The
division of labor is exact:

| structure | mutability | ordering | lookup | key requirement |
| --- | --- | --- | --- | --- |
| `std.SortedMap` | build once, then read | keys ascend | O(log n) binary search | `SortedTableCompare` comparator |
| `std.Dictionary` | mutable (`set`/`remove`/`clear`) | none (hash order) | O(1) hash | `Hashable` |

`haxe.ds.Map` and its implementations stay banned (`V13
HashMapCollection`); `std.Dictionary` is the sanctioned mutable hash
type and is not intercepted by V13. It is declared as an extern in
`samples/std/Dictionary.hx` and lowers to each target's native hash
map, exactly as `haxe.ds.Map` lowers when V13 does not apply:

| Haxe | TypeScript | Swift | Kotlin | Rust | Dart |
| --- | --- | --- | --- | --- | --- |
| `std.Dictionary<K, V>` | `Map<K, V>` | `[K: V]` | `HashMap<K, V>` | `HashMap<K, V>` | `Map<K, V>` |

No runtime resident backs `std.Dictionary`; the native maps of the five
targets are the implementation. The extern emits no file of its own, and
references lower through each target's type mapping, the same
platform-native route `haxe.Exception` takes.

## Table behavior

`std.Dictionary<K, V>` is a mutable hash table:

1. **Construction.** `new Dictionary<K, V>()` (or `new Dictionary()`
   with type parameters inferred from the binding) yields an empty
   table.
2. **Lookup.** `get(key:K):Null<V>` returns the stored value or
   `null` when the key is absent; `exists(key:K):Bool` reports
   presence without producing a value. Lookup is hash-based, O(1)
   average.
3. **Mutation.** `set(key:K, value:V):Void` inserts or overwrites the
   entry for `key`; a later `set` with an equal key replaces the
   earlier value, so exactly one entry per distinct key survives.
   `remove(key:K):Bool` deletes the entry and returns `true` when
   the key was present, `false` otherwise. `clear():Void` empties
   the table; the table then behaves as a freshly constructed one and
   accepts new entries.
4. **Ordering.** None is observable. Iteration order is the target hash
   map's own and must never reach output; any iteration over a
   `std.Dictionary` is rejected by `V01 IteratorLoop` until a
   key-listing ruling exists. The five methods above are the complete API.

## Key constraint

A `std.Dictionary` key must be `Hashable`. The sanctioned key domain
is every type whose lowering carries a native hash identity on all five
targets: `Int`, `Bool`, `String`, `Array` over a hashable
element, `Null` over a hashable type, a type parameter bound to a
hashable type, and a nested `@:dataClass` whose fields are all
hashable. `Float`, payload enums, marked value types, and the sorted
tables are not hash keys.

The hash identity itself is generated by the record Hashable/Hash
emission (the `@:dataClass` conformances of the Swift and Rust
targets); this specification consumes that generation as the key
constraint. Until that generation is available, the five-target translation
accepts the scalar and structural key domains, and the constraint on
`@:dataClass` keys connects when the Hashable/Hash emission is
available.

## Bans restated

`haxe.ds.Map` and its implementations remain `V13`.
`std.Dictionary` is the mutable hash keyed structure of the subset; a
sample that needs an unordered mutable keyed cache uses it, and a sample
that needs ordered keyed lookup uses `std.SortedMap`.

### Swift target rulings

#### Dictionary (stdlib/19)

`std.Dictionary` lowers to the native Swift `Dictionary` spelled
`[K: V]`. `new Dictionary()` emits `[:]`; `get` and `exists`
read the subscript (`[k]`, `[k] != nil`), `set` assigns the
subscript, `remove` lowers to `removeValue(forKey:) != nil`, and
`clear` lowers to `removeAll()`.

### Dart target rulings

#### Dictionary (stdlib/19)

`std.Dictionary` lowers to the native Dart `Map<K, V>`.
`new Dictionary()` emits `Map<K, V>()`; `get` and `exists` read
the subscript (`[k]`, `containsKey(k)`), `set` assigns the
subscript, `remove` lowers to `remove(k) != null`, and `clear`
lowers to `clear()`.
